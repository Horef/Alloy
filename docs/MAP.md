- `chatbot_eval` must not import `google` at module level (except in `chatbot_eval.llm`): only llm.py talks to the Gemini SDK; other modules depend on the StructuredLLM protocol, so they run with fakes
- `chatbot_eval` must not import `chatbot_eval.cli` at module level: cli.py is the only module that wires components together
