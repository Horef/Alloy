# docs/

Maintainer and agent documentation: project state, decisions, and the design reference (the user manual is the root `README.md`). Project state: `BRIEF.md` (goal, non-goals, open questions), `STATUS.md` (current snapshot), `WORKLOG.md` (what was done, newest first) and `DECISIONS.md` (numbered decisions, index at the top). Design: `ARCHITECTURE.md` (boundaries, invariants and an index) and `design/` (one file per component). `MAP.md` and `FACTS.md` (key defaults read from their source files) are generated by `python tools/docmap.py update`, and `RUNS.md` (an index of local evaluation and generation runs by run id) by `python tools/docmap.py runs`. `theme-layer-ab-results.md` is a dated A/B record and `theme_ab_probe.py` the offline probe that produced it. `plans/` holds multi-session plans in progress; `archive/` holds finished reviews, plans and probes, which are dated records not to be rewritten. Every other doc here opens with a `Status:` line (current, proposal, superseded or historical) that `docmap.py check` enforces.
