# src/chatbot_eval/

The `chatbot_eval` package: all of Alloy's code, one module per component, assembled into workflows only by `cli.py`. Start with `cli.py` to see how a command runs. Components receive their collaborators (a `StructuredLLM`, a `ChatbotAdapter`, a cache) as arguments, which is why the test suite can run offline with fakes. `models.py` holds the shared Pydantic contracts and `validation.py` the input checks; `contracts.py` and `cache.py` define cache identities and keys. The design and rationale of each module are in `docs/architecture.md`; the tests for `x.py` are in `tests/test_x.py`.
